# How to set up Supabase for this website:

### 1. Go to the [Supabase website](https://supabase.com/) and create an account.

### 2. Create a new project (don't adjust any of the default settings).

### 3. Go to the *SQL Editor* tab and paste the following SQL code:

```bash
/*
Create the tables
*/

create table public."user" (
  email character varying not null,
  name character varying not null,
  is_admin boolean not null default false,
  user_id uuid not null default auth.uid (),
  phone_number character varying null,
  constraint users_pkey primary key (user_id),
  constraint users_email_key unique (email),
  constraint users_user_id_fkey foreign KEY (user_id) references auth.users (id)
) TABLESPACE pg_default;

create table public.thread (
  name character varying not null,
  description text not null,
  constraint thread_pkey primary key (name)
) TABLESPACE pg_default;

create table public.post (
  post_id bigint generated by default as identity not null,
  created_at timestamp with time zone not null default now(),
  subject character varying not null,
  text text not null,
  thread_name character varying not null,
  user_id uuid not null default gen_random_uuid (),
  is_edited boolean not null default false,
  edit_time timestamp with time zone null,
  constraint post_pkey primary key (post_id),
  constraint post_thread_name_fkey foreign KEY (thread_name) references thread (name),
  constraint post_user_id_fkey foreign KEY (user_id) references "user" (user_id)
) TABLESPACE pg_default;

--Turn on RLS
alter table public.users enable row level security;
alter table public.thread enable row level security;
alter table public.post enable row level security;

--Make public.users readable without triggering the users policies
create or replace function public.is_admin()
returns boolean language sql stable security definer set search_path = public as 
$$select coalesce((select is_admin from public.users where user_id = auth.uid()), false);$$;

--Add thread policies
create policy "threads readable by signed-in users" 
    on public.thread for select
    to authenticated
    using (true);
create policy "profiles readable by signed-in users"
    on public.users for select
    to authenticated
    using (true);
create policy "users create own profile"
    on public.users for insert
    to authenticated
    with check (user_id = auth.uid() and is_admin = false);

--Add post policies
create policy "posts readable by signed-in users"
    on public.post for select
    to authenticated
    using (true);
create policy "users create own posts"
    on public.post for insert
    to authenticated
    with check (user_id = auth.uid());
create policy "users edit own posts"
    on public.post for update
    to authenticated
    using (user_id = auth.uid())
    with check (user_id = auth.uid());
create policy "users delete own posts, admins delete any"
    on public.post for delete
    to authenticated
    using (user_id = auth.uid() or public.is_admin());
```

### 4. Update the website for your specific Supabase project.

Go to the *forum.js* file found in the *js* folder of this repository and edit the values for *SUPABASE_URL* and *SUPABASE_ANON_KEY*. These values can be found in *Project Overview* -> *Server Build APIs* from inside your Supabase project (note that SUPABASE_ANON_KEY is called SUPABASE_PUBLISHABLE_KEY within Supabase).

### You're all set!

# How to create a new thread:

### 1. Go to the *Table Editor* tab in your Supabase project.

### 2. Click the *thread* table.

### 3. Select *Insert* -> *Insert Row* in the upper right corner.

### 4. Fill in the *name* and *description* boxes with your desired values.

### 5. Hit *Save*!

# How to make a user an admin:

### 1. Go to the *Table Editor* tab in your Supabase project.

### 2. Click the *user* table.

### 3. Right click anywhere on the row representing the user you want to make an admin and click *Edit row*.

### 4. Change the *is_admin* value to *TRUE* and hit *Save*!

# How to ban a user:

### 1. Go to the *Authentication* tab in your Supabase project.

### 2. Click the *Users* tab under *MANAGE*.

### 3. Click the UID of the user you would like to ban.

### 4. Scroll down on the side menu that pops up and select *Ban user*.

### 5. Set the ban duration bfore simply hitting *Confirm ban*!
